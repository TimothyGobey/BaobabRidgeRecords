## Implemented Features
* Feature 1: Add a new animal
* Feature 2: View all animals
* Feature 3: Update an animal
* Feature 4: Delete an animal
* Feature 5: Generate a summary report

## File Formats
* **animals.txt:** Stores the core data. Contains one animal per line with exactly seven fields separated by a pipe character (`|`). The fields are: `Animal ID | Name | Species | Age | Recovery Score | Status | Housing Unit`.
* **summary.txt:** A generated text file that overwrites itself each time the report is run, displaying total animals, average age, average recovery score, and a breakdown of counts per status.
