## Build and Run Instructions
1. Open `BaobabRidgeRecords.sln` in Visual Studio 2022.
2. Ensure .NET 8.0 SDK is installed.
3. Build the solution (`Ctrl + Shift + B`).
4. Press `F5` or click **Start** to run the application.

## Implemented Features
* Feature 1: Add a new animal
* Feature 2: View all animals
* Feature 3: Update an animal
* Feature 4: Delete an animal
* Feature 5: Generate a summary report

## File Formats
* `animals.txt`: UTF-8 pipe-delimited file containing 7 fields per line (`Animal ID|Name|Species|Age|Recovery Score|Status|Housing Unit`).
* `summary.txt`: Generated text report containing total count, average age, average score, and status breakdown.
